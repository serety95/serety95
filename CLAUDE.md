## README Conventions

The README follows a dark-themed, terminal/cyber aesthetic with these consistent patterns:

- **Section headers** use emoji + ALL_CAPS_SNAKE_CASE labels (e.g., `## 🛠️ TOOLKITS`, `## 🛰️ ACTIVE_TRANSMISSIONS`).
- **Color palette**: `#38BDF8` (sky blue) for titles/accents, `#34D399` (emerald) for secondary accents, `#070A13` for backgrounds, `#1E293B` for borders.
- **Font**: JetBrains Mono is used in the typing SVG banner.
- **Badges** use `style=for-the-badge` with `labelColor=1E293B` and `logoColor` matching the palette above.
- **Skill icons** are rendered via `skillicons.dev`.
- Stats cards use `theme=tokyonight` with manual color overrides to match the palette.
- Horizontal rules (`---`) separate every major section.
- The file closes with a centered `▲ End of Transmission.` tagline.

## Editing Guidelines

When updating the README, preserve the existing visual identity — color codes, badge style, section naming convention, and the closing tagline. New sections should follow the `## emoji SECTION_NAME` header pattern and be separated by `---`.

The `ACTIVE_TRANSMISSIONS` section lists current/notable projects. Update it when projects ship or new ones begin; keep entries concise (one line of bold project name + one sentence description with bolded tech).
